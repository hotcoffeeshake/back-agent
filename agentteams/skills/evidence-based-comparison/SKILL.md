# 证据化方案比较

1. 使用 `tenant_id`、设备类别和服务地点调用 `search_catalog`。
2. 仅使用当前租户和可见商户的数据，最多保留三个候选。
3. 为每个候选给出匹配理由、差异和风险，并附 `doc_id`、`version`、`chunk_id`、`score`。
4. 将所有结果标记为“待实时验证”。不得用文档内容声称实时库存、排期或价格有效。
5. 无候选、证据缺失或证据冲突时返回人工接管原因。

输出 `CandidateSet`，不得执行任何写操作。
