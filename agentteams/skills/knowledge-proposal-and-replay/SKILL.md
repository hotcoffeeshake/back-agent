# 知识提案与回测

1. 仅处理已解决、来源明确并完成脱敏的会话。
2. 检测现有知识的重复、冲突、过期和适用范围，生成最小 `before/after` Diff。
3. 运行黄金集和相关失败用例，报告总数、通过数、失败数与指标变化。
4. 回退超过 2%、出现权限扩大或新增政策承诺时将提案标为不可审批。
5. 输出 `PENDING_APPROVAL` 提案。发布服务只能由运营人员凭证触发。

不得把客户原话、未核实人工经验或模型推测直接写入知识库。
